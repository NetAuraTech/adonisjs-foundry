This is `adonisjs-foundry` — a production-ready AdonisJS v7 + Inertia/React boilerplate and headless CMS, built on a domain-driven architecture (controllers → services/repositories → models).

<critical>
- Prefer `npm` for dependency management and scripts.
- Never manually modify files in `.adonisjs/`; they are generated by AdonisJS and updated by the framework.
</critical>

## Stack

| Layer     | Technology                                   |
| --------- | -------------------------------------------- |
| Backend   | AdonisJS v7, Lucid ORM, VineJS               |
| Frontend  | React 19, Inertia.js, Tailwind CSS v4        |
| Language  | TypeScript 5.9                               |
| Database  | PostgreSQL (primary), SQLite (dev)           |
| Cache     | Redis                                        |
| Auth      | Session-based (@adonisjs/auth), OAuth (Ally) |
| Storage   | @adonisjs/drive (local, S3, R2)              |
| Real-time | @adonisjs/transmit (SSE)                     |
| Testing   | Japa                                         |

## Working Agreements

- Keep root guidance small and broadly applicable. Add detailed conventions to focused docs in `docs/agents/` when they only apply to one architectural layer.
- This is not a monorepo — all conventions in this file and in `docs/agents/` apply to the whole codebase unless stated otherwise.

## Repository Expectations

- Run `npm run lint`, `npm run format`, and `npm run typecheck` before committing code.
- Use Conventional Commits, with the description in the commit body rather than the title:
  type(scope)
  short description
  Optional body listing what was added, changed, or removed.

Types: `feat`, `fix`, `refactor`, `docs`, `chore`, `test`, `perf`. Prefer scopes that match the touched feature, e.g. `feat(auth)`, `fix(token)`, `refactor(account)`.
